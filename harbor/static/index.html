Harbor Mutual on SurrealDB

BM25 keyword search and HNSW vector search run side by side, merged with Reciprocal Rank Fusion. Switch adjuster: results change because region permissions live in the database, not in this app.

A witness should almost never appear on more than one claim. This graph query walks party → involved_in → claim to find witnesses on 3+ claims, plus the repair shops they share.

An LLM with four read-only tools, each running with the adjuster's own database token. It remembers past questions per adjuster (private memory table). Try: "Which open claims look like a fraud ring?" or "Summarise claim HM-24008".
